Embedded Hardware & Proteus Simulation Project 01

1. Traffic Light using Arduino, ESP8266, Raspberry Pi, and AT89C51

Comparative multi-controller traffic synchronization system with hardware testing and simulation.

Designed and implemented a modular traffic light control system across 4 distinct microcontrollers: Arduino Uno, ESP8266 Wi-Fi module, Raspberry Pi SBC, and the classic AT89C51 (8051 architecture). Developed finite state machines for intersection priority timing, pedestrian safety delays, and validated all circuit logic virtually using Proteus EDA.

Hardware & Tech Used

Arduino Uno ESP8266 Raspberry Pi AT89C51 Microcontroller Proteus EDA

Key Engineering Deliverables

  • Comparative analysis of execution speeds and pin configurations.
  • Assembly and Embedded C timing algorithms for AT89C51 timers.
  • Virtual circuit debugging without risk of hardware damage.
Automation & Robotics Project 02

2. Automatic Toll Gate

Automated highway vehicle presence detection and contactless servo barrier system.

Engineered an automated toll booth management system utilizing optical proximity sensors and micro-servo motors to automatically detect oncoming vehicles, verify clearance, and safely actuate the toll barrier without manual human intervention.

Hardware & Tech Used

Microcontroller IR Proximity / RFID High-Torque Servo Motor Embedded C

Key Engineering Deliverables

  • Instant sensor response avoiding vehicular queue bottlenecks.
  • Safety debounce timer ensuring gate does not lower prematurely.
  • Low standby power consumption for long operational lifespans.
Internet of Things (IoT) Project 03

3. Smart Home Automation

Wireless Wi-Fi appliance control and monitoring ecosystem with responsive interface.

Developed an Internet of Things smart home infrastructure enabling users to toggle lights, fans, and home electrical appliances wirelessly from any smartphone or computer connected to the network. Incorporates multi-channel optocoupler relay isolation to ensure electrical safety when switching AC mains.

Hardware & Tech Used

ESP8266 NodeMCU Optocoupler Relays Wi-Fi Web Server HTML5 / CSS / JS

Key Engineering Deliverables

  • Sub-second relay response time over standard wireless LAN.
  • High-voltage isolation protecting low-voltage microcontroller pins.
  • Responsive mobile interface allowing effortless touch switching.
Machine Learning & Computer Vision Project 04

4. Leaf Disease Detection using Image Processing

Automated agricultural diagnostic pipeline in Python utilizing OpenCV and feature classification.

Created a computer vision pipeline in Python to analyze digital images of agricultural plant leaves. Applies color space transformation (RGB to HSV/Lab), background subtraction, defect isolation, and texture feature extraction to identify biological distress and disease signatures in crops for early farm protection.

Hardware & Tech Used

Python 3 OpenCV NumPy Color-Space Segmentation

Key Engineering Deliverables

  • Automatic isolation of lesion boundaries against healthy plant tissue.
  • High-contrast visual masks enabling fast diagnosis.
  • Non-destructive crop monitoring helping farmers protect harvest yields.
Full-Stack IoT Dashboard Project 05

5. Temperature and Humidity Monitoring System and Real-Time Web App

Atmospheric sensor telemetry streaming to an interactive real-time web monitoring application.

Constructed a complete environmental monitoring stack. A digital DHT atmospheric sensor wired to an ESP8266 microcontroller captures ambient temperature and relative humidity. The microcontroller streams telemetry packets over HTTP/WebSocket to a Node.js + Express backend, which dynamically updates an interactive live web dashboard with gauges, historical logging, and threshold alerts.

Hardware & Tech Used

ESP8266 Microcontroller DHT11 / DHT22 Sensor Node.js + Express Real-Time UI Charts

Key Engineering Deliverables

  • Sub-second telemetry data updates rendered on live browser graphs.
  • Configurable threshold alarms for overheating or critical humidity.
  • Persistent data recording allowing environmental trend evaluation.
